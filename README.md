# موقع محلات الهواتف

## وصف المشروع

موقع ويب متقدم وحديث لإضافة محلات الهواتف والهواتف الذكية. الموقع يتميز بـ:

- **تصميم عصري**: تصميم جميل باستخدام ألوان أزرق وأبيض
- **متجاوب تماماً**: يعمل بشكل مثالي على الكمبيوتر والتابلت والهاتف الذكي
- **7 أقسام رئيسية**:
  1. الرئيسية - قسم البداية بصورة ترحيبية
  2. المحلات - عرض محلات الهواتف المتاحة
  3. الهواتف - عرض أحدث موديلات الهواتف
  4. العروض - عروض حصرية وخاصمات
  5. الخدمات - خدمات الموقع والمحلات
  6. عن الموقع - معلومات عن الموقع والإحصائيات
  7. اتصل بنا - نموذج التواصل ومعلومات الاتصال

## المميزات

✅ **تصميم عربي كامل** - واجهة باللغة العربية مع دعم RTL  
✅ **متجاوب تماماً** - يعمل على جميع الأجهزة والأحجام  
✅ **سريع وخفيف** - لا يوجد تبعيات ثقيلة  
✅ **سهل التخصيص** - يمكن تعديل الألوان والمحتوى بسهولة  
✅ **متحرك وجميل** - تأثيرات انتقالية سلسة وجذابة  
✅ **HTML نقي** - لا يتطلب أي أطر عمل معقدة  

## الملفات

- `index.html` - الملف الرئيسي بجميع الأقسام
- `style.css` - تنسيق الموقع والألوان
- `script.js` - الوظائف التفاعلية والحركات
- `README.md` - هذا الملف

## كيفية الاستخدام

1. انسخ جميع الملفات إلى مجلد واحد
2. افتح ملف `index.html` في المتصفح
3. الموقع جاهز للاستخدام فوراً!

## التخصيص

### تغيير الألوان

عدل المتغيرات في `style.css`:

```css
:root {
    --primary-color: #0066cc;      /* اللون الأزرق الأساسي */
    --secondary-color: #003d99;    /* اللون الأزرق الغامق */
    --light-color: #f0f4f8;        /* اللون الفاتح */
    --white: #ffffff;              /* الأبيض */
    --dark: #1a1a1a;              /* الأسود */
}
```

### إضافة محلات جديدة

أضف كود جديد في قسم المحلات:

```html
<div class="shop-card">
    <div class="shop-image">
        <i class="fas fa-store"></i>
    </div>
    <h3>اسم المحل</h3>
    <p>الوصف</p>
    <p class="location"><i class="fas fa-map-marker-alt"></i> العنوان</p>
    <button class="btn btn-secondary">زيارة المحل</button>
</div>
```
